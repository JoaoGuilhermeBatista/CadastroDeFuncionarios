# CadastroDeFuncionarios

Uma API REST para gerenciamento de funcionários, desenvolvida durante o curso Java10x.  
*A REST API for employee management, built as part of the Java10x course.*

---

## Português

Projeto de estudo com foco em operações de cadastro e gerenciamento de funcionários. Conta com uma interface web simples via Thymeleaf e banco de dados em memória H2.

**Tecnologias**

- Java 21 / Spring Boot 4.0
- Spring Data JPA + Flyway
- Thymeleaf
- H2 Database
- Lombok

---

## English

A study project focused on employee registration and management. It features a simple web interface via Thymeleaf and an in-memory H2 database.

**Tech Stack**

- Java 21 / Spring Boot 4.0
- Spring Data JPA + Flyway
- Thymeleaf
- H2 Database
- Lombok
